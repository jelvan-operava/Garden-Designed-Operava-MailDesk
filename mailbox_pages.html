      Resend API operations in MailDesk

      The control surface is designed to expose every capability supported by the configured Resend API integration. API keys remain Worker secrets and are never placed in the browser.

      Emails

      Send, retrieve, update/cancel scheduled emails, batch sends, attachments, tags, reply-to, and idempotency keys.

      Domains

      Read verification status and surface SPF/DKIM readiness before production sends.

      Audiences & contacts

      Sync contacts, segments, and unsubscribe state for operational messaging.

      Broadcasts

      Inspect campaign status and delivery outcomes alongside transactional messages.

      Webhooks

      Monitor endpoint health, signature verification, retries, and individual payloads.

      Analytics

      Aggregate delivery, open, click, bounce, complaint, and suppression signals.

      Cloudflare AI automations

      Rules run after a verified Resend event. AI classification and drafting execute in Workers AI; delivery remains controlled by the Worker.

      Automation runbook

      Automations are event-driven and reviewable. Each run keeps the Resend event ID, AI decision, and resulting draft or escalation.

      • 1. Ingest
        Verify Resend/Svix signature        Worker
      • 2. Understand
        Classify intent or risk with Workers AI        AI
      • 3. Act
        Create a draft, label, notify, or suppress        Reviewable
